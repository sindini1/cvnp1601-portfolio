# Week 8 Cron Automation Cheat Sheet Entries

# Five-field cron syntax: minute hour day-of-month month day-of-week
# Example: 0 6 * * 0 = every Sunday at 6:00 AM

# crontab -e : edit the current user's crontab
# crontab -l : list the current user's crontab
# crontab -r : remove the entire crontab (risky, no confirmation prompt)

# Absolute paths are required because cron does not start in your home directory
# and does not load your interactive shell environment.

# >> : append output to a file (preserves history)
# 2>&1 : redirect stderr to the same place as stdout so errors are captured

# tail : view the end of a log file (useful for checking recent runs)
# grep CRON /var/log/syslog : show recent cron attempts
# sudo journalctl -u cron.service : alternative on systems that use journald only

# Automation evidence note: crontab -l only proves a job is scheduled.
# The script log proves the script ran and produced output.
# Syslog/journalctl proves cron attempted the job.
