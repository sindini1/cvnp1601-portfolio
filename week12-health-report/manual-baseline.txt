# Interpretation notes
Skip the first vmstat data line (it is the average since boot). The remaining samples show idle CPU near 100 percent and almost no swap or IO wait. Available memory is 3.1 GiB out of 3.8 GiB, which is the useful number. The free column is lower because Linux is using RAM for cache. Disk Use% is 22 percent. Listening services are ssh and nginx only.
